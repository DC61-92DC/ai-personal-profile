# ai-personal-profile

> 跨 AI 共享的个人档案入口。把本文件内容贴给任何 AI，它就知道该怎么跟我协作。
>
> ⚠️ **本仓库是 Public（公开）**。只写可公开的行为偏好。禁止写入：真实姓名/证件/联系方式/住址、家庭与财务信息、雇主与客户名称、项目敏感数据、令牌与密码。真实细节放本地或私有仓库。公开仓库内容会被搜索引擎、爬虫和存档站收录，**事后删除也未必撤得回**。

## 怎么用

- 新会话开头，把 `README.md` 全文作为上下文或系统提示提供给 AI。
- 或直接给 AI 这个地址：`https://github.com/DC61-92DC/ai-personal-profile`
- 档案有实质变化时：改对应章节 → 更新 `CHANGELOG.md` → 提交一个 commit。

## 版本记录与回退

Git 自带完整历史，每次修改都可追溯、可回退。

| 动作 | 命令 |
|---|---|
| 查看历史 | `git log --oneline --decorate` |
| 看某次改了什么 | `git show <commit-sha>` |
| 回退某次改动（保留历史） | `git revert <commit-sha>` |
| 阶段性快照 | `git tag v0.1.0 && git push origin v0.1.0` |

- 一次修改 = 一个 commit，message 写明改了哪一节，例如 `docs: 填充「沟通风格偏好」`。
- **禁止** `git push --force`，禁止改写已推送的历史。
- 变更摘要记在 `CHANGELOG.md`。
