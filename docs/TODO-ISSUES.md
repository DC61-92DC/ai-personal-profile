# 待办跟踪说明

本仓库用 **Issues** 跟踪档案待填条目，**Projects** 做看板（To do / In progress / Done）。

## Issue 模板

标题：`[填充] <章节名>：<具体条目>`

正文：
```
- 章节：
- 要补的内容：
- 是否包含不可公开信息：是 / 否
- 完成标准：章节已写入真实内容 + 通过隐私检查 + CHANGELOG 已更新
```

## 初始 3 条待办

1. `[填充] 六章节：把示例条目替换成真实内容` —— 只写可公开偏好。
2. `[检查] 隐私边界：确认公开仓库无敏感信息` —— 检查 README、commit 历史、Issues 正文。
3. `[例行] 季度复核：更新档案与长期目标` —— 每 3 个月复核一次，改动记入 CHANGELOG。

## 提醒

公开仓库的 commit 历史也会留痕。误提交敏感信息时，**只删文件不够**：需要改写历史或直接删仓库重建，并视情况轮换已泄露的凭据。
